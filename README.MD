## VA DB or  Variant Alliance database

```
va db implements the valkey's open source golang io client 
into microservices for ready to use interface
```

## Architecture ⚙️
it is build upon two of my favourite choice of work archi build
1. key-value
2. OBB [Object, Bucket, Branch]
for OBB, you can set any type of mode such as "DOUBLY LINKED LIST|HASH-MAP|SET"
